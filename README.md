# 🎮 Regression Quest

Selamat datang di repositori **Regression Quest**!

*Telah didesain media pembelajaran matematika yaitu game online yang dirancang menggunakan HTML (Unity WebGL) untuk memenuhi tugas matakuliah Multimedia Pendidikan Matematika. Matakuliah ini bertujuan untuk mendesain media pembelajaran pada Regresi Linier. Game matematika ini diharapkan dapat membantu guru dan siswa dalam pembelajaran.*

---

## ⚠️ PERHATIAN PENTING: PENGATURAN BROWSER ⚠️

Untuk memastikan game dapat berjalan dengan lancar tanpa *crash* atau *error* saat dimainkan di Web/Browser, Anda **DIWAJIBKAN** untuk mematikan fitur terjemahan otomatis (Auto Translate).

🚨 **Syarat Bermain:**
1. Klik ikon Google Translate (atau fitur penerjemah bawaan browser Anda) yang biasanya terletak di ujung kanan kolom URL, lalu pilih opsi: 
👉 **"Never translate this site"** (Jangan pernah terjemahkan situs ini).
2. Gunakan komputer, atau mode desktop.

**Mengapa ini harus dilakukan?**
1. Fitur terjemahan otomatis pada browser bekerja dengan cara mengubah dan memodifikasi struktur elemen HTML (DOM) pada halaman web secara paksa. Engine Unity WebGL sangat sensitif terhadap intervensi eksternal pada struktur halamannya. Jika browser mencoba menerjemahkan halaman saat game berjalan, hal ini akan memicu *error* sistemik pada memori WebAssembly (seperti *infinite loop* atau `Maximum call stack size exceeded`) yang berujung pada *crash*.
2. Game ini belum sepenuhnya disempurnakan untuk Website yang dibuka dari handphone atau HP.
